개인정보처리방침

무명사업가 대시보드 (Chrome Extension)

최종 업데이트: 2026년 5월 1일

1. 수집하는 정보

본 확장 프로그램은 서비스 제공을 위해 다음 정보를 수집합니다:

  • 이메일 주소: 로그인 및 계정 식별 목적
  • 사용자 작성 데이터: 목표, 주요 할일, Todos, 메모, 바로가기 링크
  • 프로필 정보: 닉네임, 프로필 사진 (사용자가 직접 설정한 경우)
  • 브라우저 방문 기록: 바로가기 아이콘(파비콘) 표시 및 페이지 제목 자동 완성에만 사용

2. 정보의 이용 목적

  • 대시보드 데이터의 기기 간 클라우드 동기화
  • 사용자 계정 인증 및 세션 관리
  • 바로가기 링크의 파비콘 및 제목 자동 표시

3. 정보의 저장 및 보관

수집된 데이터는 Supabase(클라우드 데이터베이스)에 암호화된 연결(HTTPS)로 저장됩니다. 로컬 데이터는 Chrome 브라우저의 storage API를 통해 사용자 기기에 저장됩니다.

4. 제3자 제공

수집된 개인정보는 법령에 의한 경우를 제외하고 제3자에게 제공하거나 공유하지 않습니다.

파비콘 표시를 위해 https://www.google.com/s2/favicons 서비스를 사용하며, 이 과정에서 바로가기 URL의 도메인 정보가 Google 서버에 전달될 수 있습니다.

5. 데이터 보관 기간

사용자가 계정을 삭제하거나 데이터 삭제를 요청할 때까지 보관합니다. 삭제 요청은 아래 이메일로 문의하시기 바랍니다.

6. 사용자의 권리

사용자는 언제든지 자신의 데이터 열람, 수정, 삭제를 요청할 수 있습니다. 확장 프로그램 내 설정에서 직접 데이터를 삭제하거나, 아래 이메일로 문의하시기 바랍니다.
