1. 처리하는 데이터 및 목적

본 확장 프로그램이 처리하는 데이터는 성격에 따라 아래와 같이 구분됩니다:

데이터 처리 방식 목적 외부 전송
이메일 주소 수집 · 서버 저장 계정 생성, 로그인 인증 Supabase (인증 서버)
사용자 작성 데이터
목표, 주요 할일, Todos, 메모, 바로가기		 사용자가 직접 입력 · 클라우드 동기화 기기 간 데이터 동기화 Supabase (사용자 본인 계정에만 저장)
프로필 정보
닉네임, 프로필 사진		 사용자가 직접 설정 · 클라우드 저장 프로필 표시, 게시판 댓글 작성자 식별 Supabase (사용자 본인 계정에만 저장)

Threads 액세스 토큰 Meta OAuth 인증 후 서버 저장 Threads API 호출 인증 Supabase (암호화 저장)
바로가기 URL 도메인 파비콘 표시 시 Google 서버 요청 바로가기 아이콘(파비콘) 표시 Google 파비콘 서비스 (도메인만, 익명)

2. 데이터 저장 위치

  • 클라우드 (Supabase): 이메일, 사용자 작성 데이터, 프로필 정보 — 로그인한 사용자에 한함
  • 로컬 기기 (Chrome storage API): 로그인 세션, 캐시 데이터 — 브라우저 내에만 저장
  • 기기 외부로 나가지 않는 데이터: 브라우저 방문 기록

3. 제3자 서비스

  • Supabase (개인정보처리방침): 사용자 계정 및 데이터 저장
  • Google 파비콘 서비스: 바로가기 아이콘 표시 목적으로 URL 도메인 정보를 Google 서버에 요청합니다. 이 과정에서 개인 식별 정보는 전송되지 않습니다.
  • Meta Platforms, Inc. (Threads API) (개인정보처리방침): 사용자가 Threads 계정 연동 기능을 선택적으로 사용할 경우 적용됩니다.
    • Threads 계정 연동: Meta OAuth 인증을 통해 액세스 토큰을 발급받습니다. 발급된 토큰은 Supabase에 암호화 저장되어 기기 간 공유됩니다.
    • 발행 데이터: 작성한 텍스트 및 첨부 이미지가 Meta Threads API를 통해 Threads에 게시됩니다.
    • 이미지 저장: 첨부 이미지는 Supabase Storage(threads-media 버킷)에 업로드된 후 공개 URL로 Meta API에 전달됩니다.
    • 이 기능은 사용자가 직접 연결을 선택한 경우에만 활성화되며, 언제든지 연결을 해제할 수 있습니다.

4. 데이터 공유 및 제3자 제공

수집된 개인정보는 법령에 의한 경우를 제외하고 제3자에게 제공하거나 판매하지 않습니다. 위 제3자 서비스(Supabase, Google, Meta Platforms)는 서비스 운영에 필요한 범위 내에서만 데이터를 처리합니다.

5. 데이터 보관 기간

사용자가 계정 삭제 또는 데이터 삭제를 요청할 때까지 보관합니다. 삭제 요청은 아래 이메일로 문의해 주세요.

6. 사용자의 권리

  • 자신의 데이터 열람, 수정, 삭제 요청 가능
  • 확장 프로그램 내 설정에서 직접 데이터 삭제 가능
  • 계정 삭제 요청 시 이메일로 문의
  • Threads 연결 해제: 확장 프로그램 내 스레드 탭에서 계정 연결을 해제할 수 있으며, 해제 시 저장된 액세스 토큰과 관련 데이터가 즉시 삭제됩니다
  • Meta 데이터 삭제: Meta의 Threads 설정에서 제3자 앱 접근 권한을 직접 철회할 수 있습니다
